О проекте

Зачем нужен сайт

Сайт создан как учебный проект. Мы хотели собрать в одном месте простую информацию о Байкале для начинающих туристов.

Что есть на сайте

  • описание основных мест для посещения;
  • галерея с фотографиями озера;
  • контакты автора проекта.

Об авторе

Проект сделан студентом в рамках лабораторной работы по веб-разработке. Сайт написан на HTML и CSS и опубликован на GitHub Pages.
